# 🎭 Advanced Usage

In this section, let’s build a **multi-section theater layout** with **custom styling**.

We will use:

- Two sections: **Balcony** + **Ground Floor**
- `onSelect` and `onUnselect` to update selected seats
- `customStyles` to fully design the look of seats

---

## Multi-Section Config

```tsx
const config = [
  {
    title: "Balcony",
    seats: {
      A: [
        { id: "A1", label: "A1" },

        { id: "A3", label: "A3" },
```

```tsx live scope={{TheaterSeatSelect}}
  // Seat configuration for multiple sections
  const config = [
    {

        D: [
          { id: "D1", label: "D1" },
          { id: "D2", label: "D2" },

      },

  ];

  const seat2 = `url("data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='64' height='64' viewBox='0 0 64 64' fill='none'><rect x='18' y='10' width='28' height='18' rx='4' stroke='black' stroke-width='4' fill='none'/><rect x='16' y='30' width='32' height='10' rx='3' stroke='black' stroke-width='4' fill='none'/><path d='M16 30 v12 q0 6 6 6' stroke='black' stroke-width='4' fill='none'/><path d='M48 30 v12 q0 6 -6 6' stroke='black' stroke-width='4' fill='none'/><line x1='24' y1='46' x2='40' y2='46' stroke='black' stroke-width='4'/></svg>")`;

  // State to track selected seats

  // Example statuses

  const reservedSeats = ["A3"];

  // Event handlers
  const handleSelect = (seat) => setSelectedSeats((prev) => [...prev, seat.id]);

  const handleUnselect = (seat) =>
    setSelectedSeats((prev) => prev.filter((s) => s !== seat.id));

    >

      <TheaterSeatSelect

        reservedSeats={reservedSeats}
        onSelect={handleSelect}
        onUnselect={handleUnselect}
        customStyles={[
          // Seat Selection Component
          {
            rowGap: "12px",
            columnGap: "16px",
            headerStyles: {
              fontSize: "18px",
              fontWeight: 600,
              color: "#ffffff",
              textTransform: "uppercase",
              marginBottom: "8px",
              padding: "4px 0",
            },
            seatStyles: {
              width: "36px",
              height: "36px",
              borderRadius: "6px",
              border: "1px solid #cccccc",
              fontSize: "14px",
              fontWeight: "bold",
              display: "flex",
              alignItems: "center",
              justifyContent: "center",
            },
            availableStyles: {
              backgroundImage: seat1,
              backgroundColor: "#28a745",
              color: "#000000ff",
              border: "2px solid #000000ff",
            },
            bookedStyles: {
              backgroundImage: seat1,
              backgroundColor: "#dc3545",
              color: "#000000ff",
              border: "2px solid #000000ff",
            },
            disabledStyles: {
              backgroundImage: seat1,
              backgroundColor: "#6c757d",
              color: "#000000ff",

            },
            reservedStyles: {
              backgroundImage: seat1,
              backgroundColor: "#ffc107",

            },
            selectedStyles: {
              // backgroundImage: seat1,

          },
          // Section 2 style

            headerStyles: {
              fontSize: "16px",
              fontWeight: "bold",
              color: "#ffffff",
              padding: "8px 0",

            seatStyles: {

              height: "30px",

              color: "#000000ff",

              backgroundImage: seat2,
              backgroundColor: "#6c757d",
              color: "#000000ff",
              border: "2px solid #000000ff",
              cursor: "not-allowed",
            },
            reservedStyles: {
              backgroundImage: seat2,
              backgroundColor: "#ffc107",

              // backgroundImage: seat2,

      </p>
    </div>
  );
}
```
